# Documentation Index

This folder is the durable project memory for Auralith. It separates confirmed direction, active plans, open ideas, and session history so future human and LLM contributors can resume work without reconstructing context.

## Entry Point

- `../AGENTS.md` - Main onboarding and operating guide for LLM/Codex sessions.

## Project Context

- `PROJECT_STATE.md` - Current repository phase, boundaries, and known status.
- `PROJECT_VISION.md` - Product identity, target users, and long-term intent.
- `TECH_STACK.md` - Chosen stack and current technology constraints.

## Product And UI Direction

- `UI_PHILOSOPHY.md` - Interface principles, interaction priorities, and anti-goals.
- `DESIGN_SYSTEM.md` - Early design-system constraints without building controls yet.
- `THEMING_SYSTEM.md` - Theme philosophy and style-theme boundaries.
- `AUDIO_MODE.md` - Audio window intent and future experience notes.
- `VIDEO_MODE.md` - Video window intent and future experience notes.

## Architecture And Feature Notes

- `ARCHITECTURE_NOTES.md` - Architecture boundaries and current non-implementation stance.
- `PLAYBACK_NOTES.md` - Playback direction and libmpv-related constraints.
- `PLUGIN_SYSTEM_IDEAS.md` - Future metadata provider and plugin concepts.

## Planning And Continuity

- `ROADMAP.md` - Project phases and current sequencing.
- `TODO.md` - Current actionable tasks and documentation maintenance items.
- `DECISIONS.md` - Accepted, proposed, rejected, and superseded decisions.
- `IDEAS.md` - Brainstorming area for uncommitted concepts.
- `SESSION_LOG.md` - Chronological record of meaningful sessions.

## Maintenance Rule

When a documentation file is added, renamed, or removed, update this index and the solution items in `Auralith.sln`.
